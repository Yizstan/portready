# PortReady

AI that helps Thai high-school students prepare their TCAS Round 1 portfolio by checking it against each university's requirements.

Prototype for **CU–TU Biztania Camp 2026, Engineering Track**.

## What it does
1. Student enters their portfolio: GPAX, English score, page count, sections, activities, awards.
2. Student picks target programs, or pastes a faculty's admission announcement and the AI turns it into a checklist.
3. PortReady scores readiness for each program (Ready / Almost / Not yet), lists what fails, and gives AI feedback on what to fix first.

## Try it
Open the live demo on GitHub Pages, or open `index.html` in any browser.

The requirement checks run fully in the browser. The AI review runs only in the Claude-hosted version of the prototype.

> Built-in university requirements are sample data for the prototype. Always confirm on the official faculty announcement and mytcas.com.
